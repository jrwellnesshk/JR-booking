# 寶天醫館 Design System

> 極簡、寧靜、優雅的中醫健康管理平台設計系統  
> 視覺繼承：奶油色（Cream）+ 灰褐色（Taupe）+ 淺綠（Sage），搭配浮雕熱帶葉片與大象圖騰。

---

## 1. 設計原則

### 1.1 品牌個性
- **寧靜（Serene）**：低飽和、溫暖的色調，減少醫療介面的焦慮感。
- **自然（Organic）**：不對稱佈局、柔和波浪、植物與動物圖騰。
- **奢華（Refined）**：襯線標題、充裕留白、細緻陰影與圓角。
- **可信（Trustworthy）**：資訊層次分明，管理後台清晰而不冰冷。

### 1.2 核心限制
- 客戶端（Web App）與管理員端（Admin Panel）共用同一套視覺語言，但資訊密度不同。
- 前台禁止自行註冊；所有註冊由後台員工完成。
- 取消 SMS / Gmail 自動通知，全面改用 WhatsApp Business API。

## 2. 視覺語言

### 2.1 色彩系統

| Token | Hex | 用途 |
|-------|-----|------|
| `--cream-50` | `#FBFAF7` | 頁面底色 |
| `--cream-100` | `#F7F4EE` | 卡片底色、hover 背景 |
| `--cream-200` | `#F0EBE1` | 分隔線、次要背景 |
| `--cream-300` | `#E8E0D2` | 邊框、disabled 狀態 |
| `--taupe-500` | `#8B7D6B` | 次要文字、icon |
| `--taupe-600` | `#6B5D4D` | 次要按鈕、邊框 |
| `--taupe-700` | `#4F4438` | 主要按鈕、強調文字 |
| `--taupe-800` | `#3E3328` | 標題、主要文字 |
| `--sage-300` | `#A8C49E` | 淺綠裝飾、健康意象 |
| `--sage-500` | `#6B9A6B` | 成功狀態、內科服務 |
| `--gold-500` | `#C9A87C` | 高級會員、手法治療 |
| `--coral-500` | `#D98B6A` | 警告、未到訪、遲到 |

### 2.2 字體

- **標題**：`Noto Serif TC` + `Cormorant Garamond` — 東方典雅與西方襯線的結合。
- **內文**：`Inter` + `Noto Sans TC` — 管理後台長篇閱讀清晰。
- **裝飾標籤**：大寫 + 寬字距（`letter-spacing: 0.18em`）。

### 2.3 陰影與圓角

- 陰影以暖灰褐色為基調，非常柔和，避免強烈對比。
- 圓角以 `--r-xl: 1.5rem` 與 `--r-2xl: 2rem` 為主，按鈕使用膠囊形（`9999px`）。

### 2.4 背景紋理

- **波浪**：使用 SVG 波浪圖層，置於頁面頂部與底部，透明度約 0.55。
- **浮雕葉片**：固定於右上與左下，使用低透明度（0.04–0.05）與細微陰影模擬浮雕。
- **大象水印**：右下大面積半透明圖騰，強化品牌識別但絕不搶眼。

## 3. 佈局系統

### 3.1 公眾頁面（Web App）
- 流動性版面：Hero 區採用非對稱雙欄，右側卡片稍微旋轉，營造輕盈感。
- 服務卡片水平排列，圓角大、陰影輕。
- 訪客模式：主要 CTA 灰顯並鎖定，附帶提示引導登入／升級。

### 3.2 管理員後台（Admin Panel）
- 固定左側邊欄（`260px`），深灰褐色背景，白色文字。
- 主內容區使用淺色卡片，資訊密集但藉由留白與陰影區隔。
- 日曆、表格、家庭樹等複雜元件使用獨立 panel。

## 4. 元件規格

### 4.1 按鈕

| 類型 | 背景 | 用途 |
|------|------|------|
| `.btn-primary` | Taupe 漸層 | 主要行動：升級、建立帳戶 |
| `.btn-secondary` | Cream 100 | 次要操作：取消、返回 |
| `.btn-outline` | 透明 + Taupe 邊框 | 公眾頁次要 CTA |
| `.btn-sage` | Sage 漸層 | 家庭會員、自然健康相關 |
| `.btn-coral` | Coral 漸層 | 異常通知、未到訪、刪除 |

- `disabled` 狀態：透明度 0.45，游標 `not-allowed`。

### 4.2 卡片與面板
- `.card`：半透明 + 毛玻璃（`backdrop-filter: blur(12px)`），用於會員側邊欄、Hero 卡片。
- `.panel`：較大圓角（`2rem`），用於管理後台主要內容區。

### 4.3 表單
- 輸入框：奶油色邊框、聚焦時 Taupe 光環。
- Switch：Cream 背景，開啟時轉為 Sage 綠。
- 強制欄位標示：後台註冊時必須勾選「保險覆蓋」。

### 4.4 標籤與狀態

| 狀態 | 樣式 |
|------|------|
| 預約成功 | `.status-confirmed`（灰褐） |
| 到訪 | `.status-visited`（鼠尾草綠） |
| 未到訪 | `.status-no-show`（珊瑚） |
| 治療中 | `.status-in-treatment`（金色） |
| 配藥中 | `.status-dispensing`（灰藍） |

## 5. 模組設計模式

### 5.1 會員與帳戶體系

#### 註冊流程
- 前台無註冊入口。
- 後台「新增帳戶」modal 強制包含「保險覆蓋」勾選。
- 註冊後客戶以電話／電郵登入。

#### 會員層級
| 層級 | 視覺標示 | 主要權益 |
|------|----------|----------|
| 一般會員 | 灰褐徽章 | 預約所有服務 |
| 高級會員 | 金色徽章 | 優先預約、健康貼士 |
| 家庭會員 | Sage 綠徽章 | 子帳戶、家長管理 |

#### 家庭帳戶
- 個人帳戶符合條件後，資料頁顯示「轉用家庭帳戶」按鈕。
- 後台以樹狀結構展示：父帳戶置頂，子帳戶以連接線向下延伸。
- 權限視覺化：
  - `< 18 歲`：綠色 chip「完整管理」。
  - `≥ 18 歲`：淺褐 chip「僅預約成功可見」。

### 5.2 預約與排程

#### 服務時長
| 服務 | 時長 |
|------|------|
| 內科開藥 | 15 分鐘 |
| 針灸 | 15 分鐘 |
| 手法治療 | 30 分鐘 |
| 小兒推拿 | 30 分鐘 |

#### 重疊預約邏輯
- 每位醫師的預約可與下一筆重疊後 15 分鐘。
- 例：10:00 手法治療（30 min）與 10:15 針灸（15 min）可共存，重疊區間 10:15–10:30。
- 視覺：重疊的第二筆預約以虛線邊框、半透明白底、縮排顯示，並標註「重疊 15 分鐘」。

#### 床位資源
- 需要長時間治療的項目可標註床位（如針灸組合）。
- 以床鈴 icon 顯示於預約卡片左下角。

#### 異常管理
- 日曆右上角設「醫師請假 / 天氣」按鈕。
- Modal 內選擇日期、時段、原因，系統自動篩選受影響預約。
- 可選 WhatsApp 批量通知，提示病人改期。

### 5.3 客戶關係與通訊

#### WhatsApp 偏好中心
- 會員可在設定中獨立開關：天氣通知、預約確認、健康貼士。
- 後台取消 SMS / Gmail 自動通知選項，改為顯示「已停用」。

#### 遲到追蹤
- 前台僅顯示「預約成功」。
- 後台客戶詳情頁顯示：總遲到次數、累計遲到分鐘數、歷次明細。
- 列表中以 pill 標示「準時」或「遲到 N 次」。

### 5.4 官網與收入報表

#### 官網
- 首頁流動版面、波浪背景、浮雕葉片與大象。
- 選單列設「醫師團隊」、「成功案例」。
- 案例頁匿名化處理，符合醫療廣告法規。

#### 收入報表
- 財務儀表板設「Excel 資料匯入」按鈕。
- 必需欄位：日期、金額、服務項目、客戶名稱（建議加上醫師）。
- 上傳後即時更新：總收入、本月收入、服務佔比、趨勢折線圖。

## 6. 響應式策略

- **Desktop**：完整 sidebar + 多欄佈局。
- **Tablet**：sidebar 改為頂部水平導覽，部分網格改為 2 欄。
- **Mobile**：單欄堆疊，日曆可橫向捲動，公眾頁 Hero 改為單欄。

## 8. 實作注意事項

- 所有 HTML 原型均使用同一 `design-system.css`，實際開發時可直接轉譯為 Tailwind 配置或 CSS 變數。
- Chart.js 僅用於 `admin-finance.html` 趨勢圖；若需離線使用，可改為 SVG 圖表。
- 浮雕效果依賴低透明度與細微 `drop-shadow`，不建議使用高對比圖片，以免破壞寧靜氛圍。
- 家庭帳戶權限為核心業務邏輯，前端僅展示權限 chip，實際資料權限必須於後端驗證。
