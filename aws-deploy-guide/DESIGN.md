# DESIGN.md — 寶天醫館 AWS 上線教學（新手版）

## 畫布與母版
- 1280×720；安全區 padding 上下 20 / 左右 64。
- A 標題塊 0–120px（主標題 34px bold）；B 內容區 120–660px；C 頁腳 660–720px（左：寶天醫館 · AWS 上線教學；右：NN / 18，14px 灰）。

## 色彩系統（≤4 hex + 文本中性）
- 主色 cream `#F0E4D2`（頁面底色 / 大色塊）≤60%
- 輔色 sage `#7E9476`（卡片 / 標題欄 / 圖示底）≤30%
- 強調 cocoa `#5D4037`（重點字 / 強調塊）≤10%（Hero 可 15-20%）
- 警告紅 `#C0392B`（只喺預警卡 / 警示 icon，≤10%）
- 文本 `#3E2A1E`（深棕正文）
- 漸變：`linear-gradient(135deg,#7E9476 0%,#5D4037 100%)` 用於標題欄 / 封面主視覺。

## 字體系統
- 標題 / 正文統一 `Microsoft YaHei`（保證 Windows PowerPoint 可顯示）。
- 封面主標 60–72px bold；章節大字 64px bold；頁面主標 34px bold；卡片小標 22px bold；正文 18–20px / lineHeight 1.6；頁碼 14px。
- 代碼：CodeBlock 自帶等寬字體（github-dark）。

## 密度與配圖
- 內容頁留白 ≤35%；每頁 ≥1 視覺錨點（icon / 大數字 / 圖）。
- 配圖：架構圖、安全分層圖用內聯 `<svg>`（結構化允許）；封面主視覺用 SVG 抽象雲端+診所十字；其餘用 FAIcon + CodeBlock。
- 全篇統一：圓角 12–16px、卡片浮起陰影 `0 4px 20px rgba(62,42,30,.08)`、sage 做 icon 底。
