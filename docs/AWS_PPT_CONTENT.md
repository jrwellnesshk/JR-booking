## 第 4 頁：部署架構

### 系統架構圖

```
                    ┌─────────────┐
                    │  手機 App   │
                    │ (iOS/Android)│
                    └──────┬──────┘
                           │ HTTPS
                    ┌──────▼──────┐
                    │  PWA 網頁版  │
                    │ (手機瀏覽器) │
                    └──────┬──────┘
                           │
  用戶 → Route 53 (DNS) → EC2 (Ubuntu)
    → Caddy (HTTPS) → Node.js (App)
      → SQLite (DB) → S3 (備份)
```

- **Route 53**：域名解析
- **EC2**：雲端伺服器（同時服務 Web + Apps）
- **Caddy**：自動 HTTPS 證書
- **S3**：資料備份存儲
- **CloudWatch**：監控告警
- **Apps**：PWA（手機網頁）+ 原生 App（iOS/Android）

## 第 12 頁：PWA 部署方案

### 什麼是 PWA？

- **Progressive Web App**（漸進式網頁應用）
- 手機瀏覽器打開網站 → 「添加到主屏幕」→ 變成 App 圖標
- 支援推播通知、離線緩存、全屏顯示
- **唔需要 App Store 審核，即時上線**

### PWA 需要嘅文件

| 文件 | 用途 |
|------|------|
| `manifest.json` | App 配置（名稱、圖標、顏色） |
| `sw.js` | Service Worker（離線緩存） |
| `icon-192.png` | App 圖標 192x192 |
| `icon-512.png` | App 圖標 512x512 |

### PWA 部署步驟

1. 建立 `manifest.json` + `sw.js`
2. 在 `index.html` 加入引用
3. 部署到 EC2（已有）
4. 用戶手機訪問 → 添加到主屏幕
