## 6. 💰 省錢技巧

### AWS 省錢（適用第 2 年起）

| 方法 | 慳幾多 | 點做 |
|------|--------|------|
| **Savings Plans（用量承諾）** | 慳 30-40% | 承諾 1 年 EC2 用量，月費減 |
| **Reserved Instances（預繳）** | 慳 40% | 預付一年 EC2 |

> 範例：方案 A 第 2 年用 Savings Plans，可將 ~$140 減到 ~$95。

## 7. ⚠️ 防止意外收費（必做！）

| 動作 | 點做 | 防止乜 |
|------|------|--------|
| **設定預算告警** | AWS Console → Budgets → 設 $10/月上限 + 電郵告警 | 防止超出免費層級冇察覺 |
| **關閉冇用資源** | 刪除唔用嘅 EC2 / EBS / Elastic IP | 防止閒置收費 |
| **定期睇 Cost Explorer** | AWS → Cost Explorer → 每週睇 | 及早發現異常費用 |
| **唔好開多個實例** | 只用 1 個 t3.micro | 防止多實例重疊收費 |
| **EBS 有冇快照** | 定期刪除舊快照 | Snapshots 都收錢 |

## 9. 常見問題

### Q: 免費層級真係唔收錢？
**A:** 係。EC2 t3.micro + EBS + 部分流量，頭 12 個月免費。但要設預算告警，防止超出用戶量/流量。

### Q: 超出免費額度點算？
**A:** AWS 會電郵通知你。可以：升級付費 / 減少用量 / 用 Savings Plans 降低單位成本。

### Q: 域名要另外俾錢嗎？
**A:** 要。GoDaddy 買域名每年 ~$13，Cloudflare DNS + SSL 就免費。

### Q: 唔用 App Store，只做 PWA 得唔得？
**A:** 得！PWA 完全免費，病人用手機瀏覽器開就係 App 體驗，仲識自動更新。慳返 iOS $99 + Android $25。

### Q: 第二年好貴，點算？
**A:** 屆滿免費層級後，AWS 開始收費但可用 Savings Plans 慳 30-40%。如果未夠負擔，可考慮轉平 VPS（如 Vultr $6/月）。
