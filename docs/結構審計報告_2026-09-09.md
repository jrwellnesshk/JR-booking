## 六、環境注意（OneDrive）

1. `rm` / `git mv` 喺 OneDrive 目錄**成日 SIGTERM**，但 **SIGTERM ≠ 失敗** —— 要逐個 verify，唔好靠 exit code
2. 細批量（3–4 個檔）執行；一次過剷一大堆會被截斷
3. **中文檔名喺 bash 會 encoding mismatch**（`git mv "功能驗證報告_2026-09-03.md"` → `fatal: bad source`）。用 glob（`*報告*`）或 PowerShell
4. `.gitignore` 陷阱：`_*.js` 全域 ignore，日後新增 QA 腳本要記得加 `!` 例外
