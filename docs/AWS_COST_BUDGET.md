## 5. 預算告警設定

### AWS Budgets

1. AWS Console → **「Budgets」**
2. 建立預算：
   - Budget name：`potin-clinic-budget`
   - Budget amount：$10 USD（月費上限）
   - Email alerts：你嘅電郵
   - 閾值：80%（預警）、100%（超支）

### 成本監控

```bash
# 在 AWS Console 查看成本
# 1. 去 https://console.aws.amazon.com/cost-reports/
# 2. 選擇時間範圍
# 3. 檢視各服務嘅費用

# 在伺服器上查看 S3 用量
aws s3 ls --summarize --human-readable s3://你嘅bucket/
```

## 8. 常見問題

### Q: 免費層級真係唔收錢？

**A:** 係，12 個月內 t3.micro 伺服器完全免費。但要注意：
- 超出免費額度會收費
- 設定預算告警防止意外

### Q: 如果超出免費額度點算？

**A:** AWS 會發電郵通知你。你可以：
1. 升級到付費方案
2. 優化用量
3. 設定預算告警

### Q: App 上架要幾錢？

**A:**
- iOS：$99/年（約 HK$775）
- Android：$25 一次性（約 HK$195）
- PWA：免費

### Q: 點樣避免意外費用？

**A:**
1. 設定 AWS Budgets 告警
2. 定期檢查 Cost Explorer
3. 用免費層級內嘅服務
4. 設定 EC2 停止時間表

### Q: 如果我唔用 App Store？

**A:** 可以用 PWA，完全免費，唔需要 App Store 審核。
