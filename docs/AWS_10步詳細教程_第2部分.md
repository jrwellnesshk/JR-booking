# 步驟 4：連接伺服器（5 分鐘）

## 4.1 找到你嘅 .pem 金鑰文件

你之前下載咗 `potin-key.pem` 文件，佢應該喺你嘅 Downloads 目錄：

```
C:\Users\你嘅用戶名\Downloads\potin-key.pem
```

**⚠️ 預警：**
> 如果搵唔到，去 Downloads 目錄搜尋「potin-key」
> 如果真係搵唔到，去 EC2 控制台重新建立金鑰對

---

## 4.2 打開 PowerShell

### Windows 10/11 用戶：

1. 按 **Windows 鍵**
2. 輸入 **PowerShell**
3. 點擊 **Windows PowerShell**

## 6.7 在 .env 中填寫設定

**在 nano 編輯器中：**

1. 用方向鍵移動游標到 **SESSION_SECRET=** 後面
2. 刪除現在嘅值（如果有的話）
3. 輸入你剷生成嘅 SESSION_SECRET

**如何顯示 SESSION_SECRET 嘅值：**

先按 `Ctrl+X` 退出 nano（唔好儲存），然後輸入：

```bash
echo $SESSION_SECRET
```

你會見到一個長字串，例如：

```
┌─────────────────────────────────────────────────────────────────┐
│  sAm2HaVQdnAbzDkYCC-ddvrofAwgpaSPeQrwnVhqXvM8HJroQl_dGW43U5  │
└─────────────────────────────────────────────────────────────────┘
```

**複製呢個字串**，然後重新打開 nano：

```bash
nano .env
```

在 .env 文件中：

```
SESSION_SECRET=你複製嘅字串
```

**其他需要修改嘅行：**

```
# 必須
SESSION_SECRET=你複製嘅字串
NODE_ENV=production
PORT=4000

# 初始管理員密碼（建議設強密碼）
ADMIN_PASSWORD=你嘅強密碼_至少12位

# 資料庫
DB_PATH=/app/data/database.db

# Email（Gmail）
EMAIL_USER=你嘅Gmail@gmail.com
EMAIL_PASS=你嘅16位Gmail App Password

# WhatsApp（暫時留空）
WHATSAPP_PROVIDER=twilio
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
TWILIO_PHONE_NUMBER=
TWILIO_MESSAGING_SERVICE_SID=
TWILIO_WHATSAPP_NUMBER=

# Stripe（暫時留空）
STRIPE_SECRET_KEY=
STRIPE_WEBHOOK_SECRET=
STRIPE_PRICE_MONTHLY=
STRIPE_PRICE_QUARTERLY=
STRIPE_PRICE_ANNUAL=

# 域名
SITE_DOMAIN=你嘅域名.com
```

**⚠️ 重要提醒：**
- **千祈唔好留 `CAPTCHA_TEST_BYPASS=test999` 呢行！** 呢個係測試後門
- SESSION_SECRET 已經自動生成咗
- ADMIN_PASSWORD 設一個強密碼（至少 12 位，包含大小寫+數字+符號）
