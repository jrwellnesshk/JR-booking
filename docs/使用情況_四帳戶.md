# 寶天醫館 · 四帳戶使用情況總覽（含步驟）

> 系統：booking-aurora（Express 5 + SQLite + Vue 3）
> 適用版本：2026-09-08 狀態
> 四類帳戶：**管理員 (admin)**、**員工 (staff)**、**醫師 (doctor)**、**客人 / 訪客 (customer/guest)**

---

## 0. 登入與角色分流

所有角色共用同一登入頁 `index.html`（官網登入卡）。

1. 打開官網首頁，右上角或「會員登入」錨點開啟登入卡。
2. 登入卡頂部切換角色：
   - **會員登入** → 客人帳戶（customer）
   - **醫師登入** → 醫師帳戶（doctor）
   - **員工 / 管理員登入** → 職員帳戶（staff / admin）
3. 輸入帳號（會員 ID）+ 密碼 + 驗證碼（captcha）。
4. 後端按帳號的 `role` 自動分流：
   - `customer` → 跳轉官網會員中心
   - `doctor` → 跳轉 `doctor.html`
   - `staff` → 跳轉 `staff.html`
   - `admin` → 跳轉 `admin.html`

> 備註：客人帳戶**不公開自助註冊**（`allow_public_registration` 預設關閉），新會員一律由職員後台開戶。訪客可**免登入**直接預約「初體驗」服務。
> 管理員預設帳號：`admin` / `admin123`。

## 1. 管理員帳戶 (admin) — `admin.html`

管理員擁有絕大多數權限。左側選單 `currentView` 切換以下功能區。

### 1.1 儀表板 (dashboard)
- 總覽：用戶總數、醫師數、員工數、今日預約數等指標卡。
- 步驟：登入後預設停留儀表板，查看各項統計。

### 1.2 預約管理 (bookings)
- 檢視全部預約列表，按日期／醫師／狀態篩選。
- 步驟：
  1. 點「預約管理」→ 列表載入。
  2. 用篩選器（日期、醫師、狀態）縮小範圍。
  3. 點單張預約 → 改狀態（確認／完成／未到／取消）、記錄遲到分鐘、或直接改單（時間／醫師／服務）。
  4. 儲存後系統發送對應通知。

### 1.3 初體驗預約 (trialbookings)
- 專門管理「訪客免登入」預約的初體驗單。
- 步驟：點「初體驗預約」→ 檢視／跟進訪客預約；可聯絡轉為正式會員。

### 1.4 收入 (income)
- 收入統計報表。
- 步驟：點「收入」→ 選時間範圍 → 檢視營收明細。

### 1.5 用戶管理 (users)
- 列出全部用戶（含角色、保險標記、VIP/備註）。
- 步驟：
  1. 點「用戶管理」→ 列表。
  2. 新增用戶：選角色（客戶／醫師／員工／管理員）→ 填姓名、電話、電郵、保險覆蓋等 → 系統生成帳號＋臨時密碼。
  3. 編輯備註（VIP、敏感標記）。
  4. 重設他人密碼 → **需二次驗證（輸入自己密碼）**。
  5. 刪除用戶 → **需 2FA 且連帶刪除關聯資料**。

### 1.6 會員付款 (member-payments)
- 會員訂閱／付款記錄查閱。
- 步驟：點「會員付款」→ 檢視各會員訂閱狀態與付款紀錄。

### 1.7 家庭樹 (familytree)
- 檢視家庭帳戶結構（戶主＋子帳戶）。
- 步驟：點「家庭樹」→ 展開家庭關係圖；可移除成員連結。

### 1.8 病歷記錄 (medicalrecords)
- 全店客戶病歷檢視（管理員＋員工可看）。
- 步驟：
  1. 點「病歷記錄」→ 列表（按客戶／醫師／日期篩選）。
  2. 點開單張病歷 → 看診療紀錄、療程進度、上傳的相片。
  3. 下載錄音檔（admin/staff 權限）。

### 1.9 時段管理 (timeslots) — 含醫師請假審批
- 醫師返工月曆（Google 日曆式拖掃）。
- 步驟：
  1. 點「時段管理」→ 月曆載入，每格顯示醫師名＋顏色狀態（上班／休息／請假）。
  2. 改單一醫師時段：點格 → 設 open / rest / blank。
  3. 批量改：拖掃選範圍 → 一次套用。
  4. **醫師請假審批**（關鍵流程）：
     - 左側「醫師請假」隊列顯示待批申請。
     - 點「批准」→ 該醫師當日時段被封鎖；若有已約客人，系統標 `needs_arrange` 並通知客人「唔使改期，會安排第二位醫師，請 OK」。
     - 批准後若仍有 `needs_arrange` 預約（琥珀色「待安排第二位醫師 (N 張)」），管理員／員工可在下拉選**補位醫師** → PATCH 落實：系統校驗補位醫師該時段有位（open+未滿），得閒則轉嫁＋通知「已安排 X 醫師」。
     - 「拒絕」→ 請假失效，時段恢復。
     - **全診所休診**：醫師提交時選「全診所」→ 當日所有醫師時段封鎖，公開預約引擎亦同步封診。

### 1.10 診所設定 (clinic-settings)
- 醫師、服務、床位、營業時間、通知開關等。
- 步驟：
  1. 點「診所設定」。
  2. 醫師頁：新增／編輯／停用（軟刪除）醫師。
  3. 服務頁：新增／編輯／刪除服務項目。
  4. 床位／營業時間／通知開關：按診所實際設定填寫並儲存。

### 1.11 系統 (system → triage / faqs)
- 醫療分流問題管理、FAQ 管理。
- 步驟：點「系統」→「分流問題」增刪改分流題與選項；「FAQ」維護常見問題。

### 1.12 審計 (audit)
- 操作日誌查閱。
- 步驟：點「審計」→ 檢視誰在何時做了什麼。

### 1.13 反饋 (feedback)
- 客戶意見回饋管理。
- 步驟：
  1. 點「反饋」→ 列表（含未讀數）。
  2. 點開 → 閱讀客戶反饋、標記已讀。
  3. 回覆 → 客戶端收到回覆通知。
  4. 可改狀態或刪除。

### 1.14 通知 (notifications)
- 節氣／節日通知、設定、發送記錄。
- 步驟：
  1. 點「通知」→ 檢視即將到來節氣／節日。
  2. 設定：開關各類通知、編輯節氣自訂訊息。
  3. 手動發送：測試通知／手動執行節氣／節日／天氣／預約提醒；或「執行全部」。
  4. 查看發送記錄（logs），可單條刪除或清空。

### 1.15 網站內容 (siteContent)
- 官網 CMS：公告、影片、社交連結、客戶評價審核、討論區管理、動態文字、成功案例。
- 步驟：
  1. 點「網站內容」。
  2. 公告／影片／案例：新增／編輯／刪除；影片可上傳檔案。
  3. 評價：審核客戶提交的評價（通過／拒絕）。
  4. 討論區：刪除不當帖子或回覆。
  5. 動態文字：維護官網文案。

### 1.16 考勤 (attendance) — 自我 + 全 HR 管理
- 管理員自身打卡，以及全診所 HR 管理。
- 步驟：
  1. 自我：點「考勤」→ 上班／下班打卡；睇自己考勤記錄。
  2. 全店管理：員工名冊、手動加考勤、排班例外、診所休息日、請假審批（全部請假）、薪資報表與匯出、考勤報表。

## 2. 員工帳戶 (staff) — `staff.html`

員工權限較管理員收窄：可看客戶資料與全店病歷、處理預約、設補位、自助 HR、**客戶帳戶管理**（開戶／改備註／代改會員級別／重設密碼——均經 `/api/admin/users` 並需輸入 admin 密碼做 2FA，見 §6），但**不可**診所設定／內容管理／通知管理／反饋管理／家庭樹等 admin-only 功能。

左側 `mainTab` 切換：列表 / 日曆 / 病歷 / 考勤 / 自助 / 時段。

### 2.1 列表 (list) — 預約列表
- 步驟：
  1. 點「列表」→ 預約清單（可篩選醫師／日期／狀態）。
  2. 點單張 → 改狀態、記錄遲到、改單（時間／醫師／服務）。
  3. 儲存。

### 2.2 日曆 (calendar) — 預約日曆
- 步驟：點「日曆」→ 月曆檢視預約分佈（含假期標記）；點日看當日預約。

### 2.3 病歷 (records) — 全客戶病歷
- 步驟：點「病歷」→ 載入全店病歷；點開看診療紀錄、療程進度、相片、可下載錄音。
  （員工可看全店病歷，唯寫入病歷限醫師本人單。）

### 2.4 考勤 (hr) — 自我打卡
- 步驟：
  1. 點「考勤」→ 顯示今日是否已打卡。
  2. 按「上班打卡」／「下班打卡」。
  3. 檢視自己考勤記錄、請假記錄、薪資單、HR 文件（上傳／下載）。

### 2.5 自助 (ess) — 員工自助服務
- 步驟：點「自助」→ 編輯個人檔案、查排班／值勤、申請請假、上傳 HR 文件。

### 2.6 時段 (timeslots) — 醫師返工月曆
- 與管理員同款的月曆；可批量改時段、並在醫師請假隊列中**選補位醫師**（設 `reassigned_to`）。
- 步驟：
  1. 點「時段」→ 月曆。
  2. 批量改醫師時段。
  3. 請假隊列中對待安排單 → 選補位醫師 → 落實轉嫁。

## 3. 醫師帳戶 (doctor) — `doctor.html`

醫師聚焦自身排程、預約、病歷、考勤。底部 `docTab` 切換：預約 / 排程 / 考勤 / 時段 / 自助 / 更多。

### 3.1 預約 (bookings) — 自己名下預約
- 步驟：
  1. 點「預約」→ 列出指派給自己的預約。
  2. 點單張 → 改狀態（僅限自己單）、記錄遲到。
  3. 於預約詳情可撰寫／更新**該次病歷**（僅自己單可寫）。

### 3.2 排程 (schedule) — 請假與排班
- 步驟：
  1. 點「排程」→ 檢視自己排班與請假記錄。
  2. 申請請假：選日期、時段、是否「全診所休診」→ 提交（狀態 pending，等 admin 批）。
  3. 可刪除自己未批的請假；**不可**批自己的請假（僅 admin 可批）。

### 3.3 考勤 (attendance) — 打卡
- 步驟：點「考勤」→ 上班／下班打卡；檢視考勤記錄。

### 3.4 時段 (timeslots) — 自己時段月曆
- 步驟：點「時段」→ 檢視／批量改自己時段狀態。

### 3.5 自助 (ess) — 員工自助
- 步驟：點「自助」→ 個人檔案、薪資單、HR 文件、請假申請。

### 3.6 更多
- 跳轉其他頁面／登出。

## 4. 客人帳戶 (customer / guest) — `index.html`

客人使用**公開官網**＋**登入後會員中心**。

### 4.1 瀏覽公開官網（免登入）
- 步驟：首頁可看醫師介紹、服務項目、會員計劃、家庭計劃、客戶評價、中醫討論區、常見問題、假期／節氣資訊。
- **AI 問診（公開）**：首頁 AI 問診入口 → 回答症狀分類問題 → 取得建議（免登入）。
- **醫療分流（公開）**：依分流問題與可約醫師／服務對應選擇。

### 4.2 訪客初體驗預約（免登入）
- 步驟：
  1. 點「初體驗預約」按鈕 → 開啟訪客預約流程。
  2. 揀服務（**僅「初體驗」可約**，其餘服務需登入會員）。
  3. 揀醫師 → 揀日期與時段（顯示可用性＋床位）。
  4. 填姓名／電話／備註 → 確認預約。
  5. 系統建立初體驗預約並通知。

### 4.3 會員登入 / 密碼救援
- 步驟：
  1. 點「會員登入」→ 輸入會員 ID＋密碼＋驗證碼 → 進會員中心。
  2. 忘記密碼：點「忘記密碼」→ 收驗證碼（Email/WhatsApp）→ 重設。
  3. 找回會員 ID：點「找回會員 ID」→ 姓名＋Email 查詢。

### 4.4 會員中心（登入後 `setView`）
左側選單切換：

- **立即預約 (booking)**
  - 步驟：揀服務 → 服務有分級門控：
    - 一般會員（general）：**僅可約「初體驗」**。
    - 高級（premium）／家庭（family）：可約全部服務（針灸、推拿、內科等）。
  - 揀醫師 → 日期時段 → 確認。

- **我的預約 (myBookings)**
  - 步驟：檢視自己預約；可改期（鎖定／已確認單受限）、取消預約。

- **我的病歷 (myMedical)**
  - 步驟：檢視自己病歷＋療程進度；下載錄音；可記錄自身療程進度（自動建 minimal 病歷）。

- **會員中心 (myMembership)**
  - 步驟：
    1. 檢視當前 tier（general / premium / family）。
    2. 升級：選 plan → Stripe 安全付款（Visa/Mastercard/Apple Pay/Google Pay）；或致電職員轉數快／現金代開。
    3. 家庭帳戶：購買家庭會員後「啟用家庭帳戶」→ 連結家庭成員（輸入家人帳戶名稱／電話；18 歲以下子女可由診所代開子帳戶）。
    4. 隱私設定：18 歲以上子成員可開關「不給主帳戶看我資料」。

- **優惠券 (coupons)**
  - 步驟：查自己優惠券＋剩餘免費診症次數；購買優惠券（Stripe）；或輸入密碼兌換（加免費診症次數）。

- **設定 (mySettings)**
  - 步驟：改個人資料（電話／電郵／地址）、改密碼（需舊密碼）、通知偏好（WhatsApp）、上傳／設頭像。

- **AI 客服 (aiCustomerService)**
  - 步驟：輸入問題 → AI 客服回覆。

- **意見反饋 (feedback)**
  - 步驟：提交反饋 → 之後可查自己反饋與未讀回覆數、標記已讀。

- **中醫討論區 (forum)**
  - 步驟：瀏覽帖子；發新帖；回覆帖子。

- **客戶評價**：於官網評價區提交評價（待審核後公開）。

- **家庭成員代辦（戶主）**：於會員中心／家庭帳戶代約 18 歲以下子女預約、查子女病歷與預約（18+ 子女僅顯示成功狀態，視乎隱私開關）。

## 6. 已知範圍與備註

- **公開註冊關閉**：新會員由職員後台開戶（符合私隱與病歷準確性要求）。
- **會員門控**：一般會員（general）僅可約「初體驗」；進階服務需 premium／family。
- **醫師請假 → 手動安排**：批准後不自動轉醫師，標 `needs_arrange` 並通知客人；客人 OK 後由 admin／staff 手動 PATCH 安排第二位。
- **全診所休診**：選「全診所」的請假會封鎖當日所有醫師時段，並同步公開預約引擎封診。
- **2FA 保護**：用戶刪除、他人密碼重設、會員級別代改（員工）等敏感操作需二次驗證。
- **Stripe / WhatsApp 通知**：為可選外部整合，不在本次場景測試覆蓋範圍（按專案約定）。
